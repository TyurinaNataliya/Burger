# AGENTS.md

Инструкции для агентов, работающих с этим репозиторием.

## О проекте

Лендинг бургерной: HTML + CSS + TypeScript (только меню-компонент). Без сторонних фреймворков. Язык интерфейса — русский.

## Ключевые команды

```bash
npm start        # сборка TypeScript (tsc) + запуск сервера на http://localhost:3000
npm run build    # только компиляция TS (src/*.ts -> js/*.js)
python -m http.server   # альтернативный статический сервер (http://localhost:8000)
```

`js/menu.js` — скомпилированный артефакт, правится только через `src/menu.ts`.

## Архитектура и соглашения

- **Страницы**: `index.html` (главная) и `menu.html` (меню). При добавлении новых страниц подключайте только нужные CSS-файлы и сохраняйте существующую разметку и классы.
- **Стили**: разбиты на компоненты в `style/`. Порядок подключения в `index.html` важен:
  - `base.css` — сброс, `body`, `.container`, кнопки;
  - `header.css` — hero-секция главной (`.main`, `.text`, `.visual`);
  - `main.css` — основной контент главной (блоки `.promo`);
  - `menu.css` — страница меню (`.menu-header`, `.nav`, `.tabs`, `.cards`, `.card`, `.pagination`);
  - `footer.css` — футер (`.footer`, `.item`, `.tel`).
  Новые стили добавлять в файл соответствующего компонента/страницы.
- **Меню-компонент**: `src/menu.ts` — данные в массиве `MENU` (категории с `items`), переключение вкладок, пагинация по 6 позиций. Детали: из типа `MenuItem` (name, desc, price); картинки — временные заглушки `burger.png` (константа `PLACEHOLDER_IMG`), при замене на реальные фото меняйте константу или добавляйте поле `img`.
- **Адаптивность**: медиазапросы (`1024px` планшет, `576px` мобильный) лежат в файле того компонента, к которому относятся.
- **Навигация**: ссылки между страницами — относительные (`index.html`, `menu.html`). «заказать» и «Меню» ведут на `menu.html`.
- **Классы**: смысловые английские имена (`main`, `container`, `promo`, `visual`, `item`, `tel`). Не вводите новые префиксы без необходимости.
- **Цвета**: палитра фиксированная — тёмно-синий `#1E2F40`, оранжевый `#FBB731`, акцент `#F37335`. Используйте те же hex-значения, не изобретайте новые.
- **Шрифты**: `Open Sans` подключён в `<head>` через Google Fonts. Для новых текстовых стилей используйте его же.
- **Изображения**: хранятся в `image/` и подключаются относительными путями (`image/burger.png`, `../image/bg-left.png` внутри CSS).

## Нюансы

- Кнопки и ссылки меню (`#`) — заглушки без реальных адресов.
- CSS задаёт `font-family: 'Nunito Sans'` для `body`, но сам шрифт не подключён (подключён только `Open Sans`). При необходимости исправьте подключение.
- В `h1` время работы и «Лучшие бургеры» — в одном заголовке через `<span>`.
- Демонстрационные данные (адрес, телефоны, скидки) не менять без указания пользователя.
