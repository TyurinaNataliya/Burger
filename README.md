# Burger

Лендинг бургерной: фирменные бургеры, акции и доставка за 30 минут.

Заказ бургеров: главная страница (акции) + страница меню с карточками блюд.

## Структура проекта

```
Burger/
├── index.html        # Главная страница (акции, hero)
├── menu.html         # Страница меню (динамический компонент)
├── server.js         # Локальный сервер (Node.js, без зависимостей)
├── package.json      # npm-скрипты (start, build)
├── tsconfig.json     # Настройки компиляции TypeScript
├── src/
│   └── menu.ts       # Источник меню-компонента (TypeScript)
├── js/
│   └── menu.js       # Скомпилированный из menu.ts скрипт
├── style/
│   ├── base.css      # Сброс, body, контейнер, кнопки
│   ├── header.css    # Hero-секция («Лучшие бургеры», главная)
│   ├── main.css      # Основной контент главной (акции .promo)
│   ├── menu.css      # Страница меню (компонент, вкладки, пагинация)
│   └── footer.css    # Футер (ссылки, контакты, телефоны)
└── image/
    ├── Logo.svg      # Логотип в шапке и футере
    ├── burger.png    # Изображение бургера
    ├── bg-left.png   # Фон блока «Скидка -20%»
    ├── bg-right.png  # Фон блока «Бесплатная доставка»
    └── .gitkeep
```

## Меню-компонент (`src/menu.ts`)

Страница меню — один компонент на TypeScript:

- Данные блюд (категории, названия, описания, цены) — в `MENU` в `src/menu.ts`.
- Вкладки «Бургеры / Пицца / Закуски» переключают категорию.
- Показывается 6 позиций; если в категории больше 6 — появляется пагинация.
- Добавление блюд: просто добавить элемент в массив `items` нужной категории.
- После изменения `src/*.ts` пересобрать: `npm run build`.

## Навигация между страницами

- Кнопки «заказать» на главной и ссылка «Меню» в футере ведут на `menu.html`.
- Со страницы меню в шапке доступен переход обратно на главную (`index.html`).

## Секции страницы

**Главная (`index.html`):**

1. **Шапка (hero)** — заголовок «Лучшие бургеры», время работы 11:00–22:00, кнопка «заказать», изображение бургера на оранжевом градиенте.
2. **Акции (promo)** — два блока: скидка -20% для компаний от 3 человек и именинникам; бесплатная доставка от 500 ₽.
3. **Футер** — логотип, основные ссылки, контактная информация и телефоны.

**Меню (`menu.html`):**

- Три категории — «Бургеры», «Пицца», «Закуски», по 6 позиций в каждой (18 карточек).
- Картинки пока placeholder (общий `burger.png`), позже заменяются на реальные фото.

## Дизайн

- Шрифты: Google Fonts — `Open Sans` (подключён в HTML), `Nunito Sans` (задан в CSS).
- Палитра: тёмно-синий `#1E2F40`, оранжевый `#FBB731`, красно-оранжевый `#F37335`.
- Блоки акций используют фоновые изображения `bg-left.png` / `bg-right.png`.

## Запуск на локальном хосте

### Через Node.js (рекомендуется)

```bash
npm start
```

`npm start` сначала компилирует TypeScript (`tsc`), затем поднимает сервер. Если нужно только пересобрать скрипты: `npm run build`.

Сайт откроется на http://localhost:3000. Порт можно поменять переменной `PORT` (например, `set PORT=8080`).

### Через Python

```bash
python -m http.server
```

Сайт откроется на http://localhost:8000.

## Примечания

- Адрес и телефоны в футере — демонстрационные.
- Ссылки в меню и кнопки создают ссылки без адресов (`#`).
- Меню-компонент написан на TypeScript и компилируется в `js/menu.js`.
